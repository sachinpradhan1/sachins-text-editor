# Sachin's Text Editor 🎬✨

A modern, high-performance, 100% client-side web application for generating cinematic kinetic typography, animated lyrics, and subtitles on videos or solid backgrounds.

## 🚀 Live Demo on Vercel
Deployable directly to [Vercel](https://vercel.com) or [Netlify](https://netlify.com) in one click with zero configuration.

## ✨ Key Features
- **100% Client-Side**: Zero servers, zero databases, zero cloud storage costs. All video decoding, rendering, and WebM export happen on the user's device.
- **Full Video & Audio Sound Support**: Upload background videos or audio tracks with live sound in preview and crystal-clear synced sound in exported downloads.
- **5 Custom Palette Slots**: Set custom single colors or 2-color vertical blend gradients for any highlighted word.
- **Subtitles & Text Formatting**: 6 One-Word animation variations, Dynamic Kinetic Scroll, 3D Perspective, and Multi-Motion Remix.
- **High Readability**: Text stroke outline, drop shadow, and dynamic subtitle background boxes/pills.
- **Auto-Save**: Browser `localStorage` automatically saves your lyrics, styles, and color choices across browser refreshes.

## 💻 Local Development
Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari). No npm or build step required!
